# PilotHub 0.9.0-alpha.2

Alpha.2 不扩展 PilotHub 的能力边界，重点完成从第一次打开应用到成功使用第一个 Skill 的体验闭环。

## 本版亮点

### 第一次使用更清楚

首次启动引导用三个步骤说明 PilotHub 的作用：

1. 发现适合自己的 AI 能力。
2. 安装到已检测的 AI Agent。
3. 打开 Agent 并开始使用。

### 安装步骤更短

推荐能力支持快速安装。PilotHub 会检测本机可用的 Agent、选择有效目标并进入安装流程；需要自定义来源、范围或目标时，仍可使用原有高级安装方式。

安装成功后会明确显示：

- 安装了什么能力；
- 安装到哪个 Agent；
- 使用的项目位置；
- 可以输入的示例指令；
- 下一步可以打开或查看的内容。

### 能力更容易理解

推荐 Skill 卡片增加面向使用场景的信息，包括中文名称、用途、分类、来源和适用平台。用户无需先理解 `SKILL.md` 或仓库结构，也能判断一个能力是否适合自己。

### 失败时可以自助诊断

安装诊断会检查：

- GitHub 是否可访问；
- 是否检测到可用 Agent；
- 目标目录是否可写；
- Skill 格式是否有效。

诊断结果使用明确状态和处理建议，不要求用户理解命令行原始报错。

### 本地反馈默认保护隐私

设置页新增可选的本地匿名反馈：

- 默认关闭；
- 只保存在当前设备；
- 可随时清除；
- 最多保留 500 条；
- 不上传到 PilotHub 或第三方。

记录范围仅限安装结果、Agent 类型、来源类型和标准化失败类别。不会记录仓库 URL、Skill 名称、本地路径、用户内容、项目代码、文件内容或原始错误。

## 当前可用链路

```text
打开 PilotHub
    ↓
查看推荐能力
    ↓
选择 baoyu-cover-image
    ↓
安装到 Antigravity / Codex
    ↓
查看安装成功指引
    ↓
在 Agent 中调用 Skill
```

## 本版不包含

- MCP 管理
- Agent 市场
- Prompt 或 Hook 管理
- Workflow Engine
- Marketplace
- 云端账号
- 匿名反馈上传

这些能力不会在 Alpha.2 中提前加入。PilotHub 当前目标仍是稳定完成第一个外部 Skill 的安装与使用。

## 验收状态

- Web 与 Rust CI 通过；
- `baoyu-cover-image` 安装与 Agent 调用链路已验证；
- Extensions 集合健康状态与 Agent 目标可正常显示；
- 本地匿名反馈默认关闭且无网络上传逻辑。
